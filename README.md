# CapstoneChecker
Capstone Document Checker for ISU Cauayan Campus

## Usage

Run the checker against a `.txt` document:

```bash
python /tmp/workspace/axielbaldoscyn-art/CapstoneChecker/capstone_checker.py /path/to/document.txt
```

The checker validates:

1. Formatting
2. Grammar
3. Technical contents
4. Diagrams
5. Figures
6. Tables
7. References
8. Similarity
9. AI contents
10. Appendices
